Notes on the data

  • Each course is shown from its most recent report. Each report is a snapshot, stamped with when it was received; scores within a report are cumulative monthly values on a 0–100 scale.
  • Issue counts are instances, not files: one document can contribute many instances.
  • Overall scores aren't totalled across courses, because each is an average over that course's own files.
