One-time setup. You need an OAuth client from Google Cloud so this app can ask for read-only access:

  1. Go to console.cloud.google.com and create (or pick) a project.
  2. Under APIs & Services → Library, enable the Gmail API.
  3. Under APIs & Services → OAuth consent screen, configure it. For a pdx.edu account choose Internal if available; otherwise External and add your address as a test user.
  4. Under Credentials, choose Create credentials → OAuth client ID with application type Desktop app, then download the JSON.
  5. Save it as {{ client_file }} and reload this page.

The secrets/ folder is excluded from git. If your Google Workspace admin blocks third-party apps, they may need to allow this one.
